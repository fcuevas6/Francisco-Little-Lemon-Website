# Little Lemon Restaurant Website 🍋

## Overview
This React project was created as part of the Capstone Project for the Coursera Meta Front End Developer Certification course. It is a single page application that allows the customer to make a reservation and view menu items.

**LIVE LINK:** <https://little-lemon.fcuevas09.workers.dev>

## Features
+ Landing page with header and footer navigation
+ Responsive design for mobile and desktop users
+ Client-side validation form
+ Dynamic reservation confirmation message
+ Filtered "Weekly Specials" menu items

  ###### Features to add:
  + Filter menu items by categories
  + Online ordering capability

### Running this project locally

###### Live version:
[Little Lemon Restaurant](https://little-lemon.fcuevas09.workers.dev)

###### From repo:

1. Clone this project locally.
2. Run `npm install` in your bash / command line.
3. Run `npm run dev` in your bash / command line.
4. Check out the site and make a reservation to this *fictional* restaurant!
